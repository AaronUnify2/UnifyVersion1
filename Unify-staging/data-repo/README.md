# Unify-data (private)

The data behind [Unify](https://github.com/AaronUnify2/Unify):
`data/unify.json` — problems, goals, tasks and the journal.

**Keep this repository private.** Unify refuses to sync to a public one.

The Unify app writes this file through the GitHub API, one commit per save
("Update Unify data"), so the history is a record of every change. The data
model is described in the app repository's `SPEC.md`.

Started fresh on 2026-10-29.
