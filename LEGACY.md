# Legacy files

These are superseded but kept for reference. Nothing here feeds the live site
any more — editing them changes nothing.

## Superseded by Process Hub

| File | Was | Now |
|---|---|---|
| `FAQ-Editor.html` | The FAQ content editor | [Process Hub](https://aaronunify2.github.io/ProcessHub/) — edits FAQ content, knowledge base articles and process maps together |
| `FAQ.json` | The published FAQ content | `exports/FAQ.json` in the ProcessHub repository, generated by Process Hub |
| `CustomerService.html` | Call flowcharts, hand-written Mermaid | Imported into Process Hub as 112 processes and 37 articles |
| `WorkAdministration.html` | The process mapper | Its data model and step cards live on in Process Hub |

`FAQ-Editor.html` carries a banner saying so, because the two look alike and
it would be easy to spend an evening editing the wrong one.

## What reads what now

Process Hub moved to its own repository,
[AaronUnify2/ProcessHub](https://github.com/AaronUnify2/ProcessHub), with its
history, its spec (`SPEC.md`) and its terminology audit. It is served at
https://aaronunify2.github.io/ProcessHub/.

```
ProcessHub  index.html   edits everything, exports the files below
                ↓
            data/        processes.json · library.json · variables.json
            exports/     FAQ.json  ← the single source for published FAQ content
                ↓
UnifyVersion1  FAQ.html  the public page, reads
                         https://aaronunify2.github.io/ProcessHub/exports/FAQ.json
```

`processhub/index.html` and `processhub/live.html` in this repository are
redirects, so old links still arrive.

The `FAQ.json` at this repository's root is the frozen pre-Process-Hub copy.
ProcessHub keeps its own copy in `tools/sources/` for the round-trip check.
