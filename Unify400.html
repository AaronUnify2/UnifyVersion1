How to Use Unify

  1. Problems: add the things causing negative emotions in your life, with a life area, an emotion and a difficulty.
  2. Combine into a goal: on the Problems tab press "Add Goal", tap the problems that belong together, then "Combine into Goal". You can also start a goal from scratch on the Goals tab.
  3. Break goals down: use quick tasks (Task mode) or the Harada 8×8 method (Harada mode) with 8 subgoals and 8 actions each.
  4. Send to tasks: send quick tasks or Harada actions to the Tasks tab. Tick the boxes in the Harada list to send several at once. If you edit an action you already sent, "Update" changes the existing task instead of making a duplicate.
  5. Work your tasks: tick them off, add notes, schedule them in Google Calendar, and reflect on what went well.
  6. Completed: resolved problems, finished goals and archived tasks live on the Completed tab, where you can reactivate or delete them.
  7. Sync: open Settings to keep your data in a JSON file in your own private GitHub repository, so it follows you between phone and computer.

Settings & Sync

GitHub sync

Your problems, goals and tasks are saved as a single JSON file in a private GitHub repository that only you can see. This page (the app) is public, but your data never goes into the public repository.

How to create a token
  1. Create a private repository for your data (e.g. UnifyData). Tick "Add a README" so it isn't empty.
  2. On GitHub go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Under Repository access choose Only select repositories and pick just your data repository.
  4. Under Permissions → Repository permissions set Contents to Read and write. Nothing else is needed.
  5. Set an expiry date, generate it, and paste it above. When it expires, make a new one and paste it in again.

The token is kept only in this browser on this device. Other pages on the same github.io site can read this browser's storage, which is why the token should only be able to reach your data repository.

Backup & import

Export a copy of everything as a JSON file, or replace everything with a file you exported earlier. "Import from Unify 300" copies the data Unify 300 saved in this browser.

Sync conflict

The data file on GitHub was changed somewhere else (probably another device) while this device also has unsaved changes. Choose which version to keep. The other one will be replaced.

Not sure? Export this device's data first, so you can import it again later if needed.
